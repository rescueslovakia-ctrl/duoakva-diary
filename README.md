# DuoAkva Diary

Komplexný webový akvaristický denník s plánovanou aplikáciou pre iOS a Android.

## Architektúra
- Next.js / React – web
- Supabase – PostgreSQL, Auth, Storage, RLS a backend
- Vercel – web deployment
- GitHub – zdrojový kód a automatické deploymenty
- Websupport – vlastná doména a DNS

## Vercel environment variables
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

## Moduly
Akváriá, merania parametrov vody, cieľové rozsahy, údržba, technika, odhad reálneho prietoku filtrov, hodnotenie svetla, rastliny, osádka, hnojivá, odporúčania, upozornenia, fotografie a mobilná aplikácia.
